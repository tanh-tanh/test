# **App Name**: Ô Chữ Vui

## Core Features:

- Puzzle Creation: Design custom Criss Cross puzzles with a grid interface. Questions and answers must be in Vietnamese.
- Interactive Gameplay: Provide an interface for playing Criss Cross, enabling input of Vietnamese characters. A tool will determine if the user is correctly filling out the puzzle.
- Puzzle Sharing: Allow users to share their created puzzles with others via a shareable link.
- Lucky Wheel Reward: Integrate a 'lucky wheel' reward system that spins upon answering questions correctly.

## Style Guidelines:

- Primary color: Vibrant orange (#FFA500) to evoke enthusiasm and playfulness.
- Background color: Pale orange (#FFF0D4) for a warm, inviting feel.
- Accent color: Sunny yellow (#FFD700) to highlight interactive elements and rewards.
- Body and headline font: 'PT Sans', a humanist sans-serif font, for a clean, modern, and accessible feel.
- Use bright and cheerful icons, related to Vietnamese culture, to represent categories and actions within the game.
- Design a clean, grid-based layout for both the puzzle creation and gameplay interfaces, optimizing for ease of use on various screen sizes.
- Incorporate smooth, delightful animations for the lucky wheel spins, correct answer confirmations, and other interactive elements to enhance user engagement.
